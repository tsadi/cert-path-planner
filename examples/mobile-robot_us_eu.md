# Certification path: Industrial mobile robot / AMR / AGV

Markets: EU/US · Options: none

Planned duration: **28-50 weeks** (6-12 months) from design freeze.

## Standards map

| Phase | Standard | Weeks |
|---|---|---|
| Plan, hazard analysis, design review | Hazard analysis and risk assessment (ISO 12100 method) | 2-4 |
| Pre-compliance testing (in-house or lab) | Pre-compliance safety and EMC screening | 4-8 |
| Component and cell certifications | UN 38.3 lithium battery transport tests | 4-8 |
| Component and cell certifications | IEC 62133-2 portable lithium cells and batteries | 6-10 |
| Product / system safety | ANSI/A3 R15.08-1/-2 industrial mobile robots | 8-14 |
| Product / system safety | ISO 3691-4 driverless industrial trucks | 8-14 |
| Product / system safety | UL 3100 automated mobile platforms | 10-16 |
| Product / system safety | IEC 60204-1 electrical equipment of machines | 4-8 |
| EMC and radio | FCC Part 15 Subpart B unintentional radiators | 2-4 |
| EMC and radio | FCC Part 15 Subpart C intentional radiators (radio modules) | 4-8 |
| EMC and radio | EU EMC Directive 2014/30/EU (EN 61000-6-x / product family) | 4-6 |
| EMC and radio | EU Radio Equipment Directive 2014/53/EU incl. delegated cyber act | 6-10 |
| Functional safety and cybersecurity | ISO 13849-1/-2 safety functions: PL calculation and validation | 6-12 |
| Listing, factory inspection, technical file | NRTL listing, initial production inspection, follow-up service | 2-6 |
| Listing, factory inspection, technical file | CE technical file and EU Declaration of Conformity | 2-4 |
| Listing, factory inspection, technical file | EU Machinery Regulation 2023/1230 (applies from 20 Jan 2027) | 6-12 |

## Test sequence

1. **Plan, hazard analysis, design review**: starts week 0-0
2. **Pre-compliance testing (in-house or lab)**: starts week 2-4
3. **Component and cell certifications**: starts week 6-12
4. **Product / system safety + EMC and radio + Functional safety and cybersecurity** (in parallel): starts week 12-22
5. **Listing, factory inspection, technical file**: starts week 22-38

## Long poles

- Hazard analysis and risk assessment (ISO 12100 method) (2-4 wk)
- Pre-compliance safety and EMC screening (4-8 wk)
- IEC 62133-2 portable lithium cells and batteries (6-10 wk)
- UL 3100 automated mobile platforms (10-16 wk)
- EU Machinery Regulation 2023/1230 (applies from 20 Jan 2027) (6-12 wk)
